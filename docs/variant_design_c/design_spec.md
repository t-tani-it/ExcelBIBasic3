## 1. 目的

v0.4 方式 A の機能を維持し、`売上分析` シートだけを 0 から再作成する。v0.5 の強みを残し、文字階層、余白、グラフ適合性、印刷・性能の証拠を改善する。

- v0.5 と同じ 4 KPI、4 グラフ以上、8 × 24 ヒートマップ、8 スパークラインを維持する。
- v0.5 の 233 / 233 を回帰基準とする。
- デザイン点数 20 / 24 以上、重大項目に 0 がないことを合格とする。
- 外部 UI は 3〜5 件まで参照し、良い要素を Excel で再現する。

## 2. 適用範囲

- `prototype_v04.xlsx` を複製して開始する。
- 既存の見積・原価・利益シート、`売上データ`、`商品マスタ`、`制御` の PT と共有キャッシュを維持する。
- `売上分析` シートを削除し、同名の新規シートを 0 から作成する。
- 新シートは `商品マスタ` の直前、シート索引 10 に配置する。
- v0.4 と v0.5 のブック・文書は上書きしない。

## 3. v0.5 の評価

### 3.1 残す強み

- 左側のフィルタ帯。
- 2 × 2 の KPI カード。
- 3 状態ヒートマップ。
- DATA NOTE パネル。
- 8 本の列スパークライン。
- 233 / 233 の検証資産。

### 3.2 改善する弱み

- KPI 値が 24 pt で、画面全体の文字階層が弱い。
- 2 分類の円グラフは情報量が少ない。
- エリア + 折れ線は、売上と差額の関係が混雑しやすい。
- 印刷、性能、手動 UI の証拠がない。
- 画面画像がリポジトリにない。
- フィルタの現在状態を要約する導線が弱い。

### 3.3 暫定点数

v0.5 は 18 / 24。v0.6 は 20 / 24 以上を目指す。

## 4. デザインコンセプト

テーマは **Warm Slate Editorial** である。v0.5 の暖色系スレート、コーラル、アンバー、クリームを維持し、雑誌の特集ページのように「見出し、数字、比較、詳細」の順で読ませる。

- 背景は Paper、カードは White、本文は Text。
- アクセントは Coral を基本とし、Amber は差額・比較の補助に限定する。
- 余白を広げ、カードとグラフの間に明確な間隔を置く。
- 文字サイズの種類を減らし、KPI 値を大きくする。
- グラフは目的ごとに種類を変え、2 分類の円グラフを廃止する。
- アイコンは任意。使う場合も 4〜6 個までに限定する。

### 4.1 代替案

- Cool Graphite: 寒色系のグレー、ブルー、ティール。分析コンソール風。
- Paper Minimal: 白と生成り、罫線と文字中心。印刷向け。

第 1 候補を基本とし、ビルド前に参考画像と照合して 1 案に決める。3 案を全部作らない。

## 9. グラフ

| ID | 目的 | 種類 | ソース | アンカー | タイトル |
|---|---|---|---|---|---|
| `PG-C01` | 月別売上 | 折れ線（マーカー付き） | `PT-03` の値を参照する補助範囲 | `D15` | 月別売上（万円） |
| `PG-C02` | 前年比較 | 2 系列の折れ線 | `PT-08` | `K15` | 2025 年と 2026 年の比較（万円） |
| `PG-C03` | 商品別順位 | 横棒 | `PT-02` | `D32` | 商品別売上（万円） |
| `PG-C04` | 業種構成 | 100% 積み上げ横棒 | `PT-01` の値を参照する補助範囲 | `K32` | 業種構成（%） |

### 9.1 共通ルール

- グラフ背景は White、外周線は Border。
- タイトルは 11〜12 pt、Navy、太字。
- 軸と目盛線は Gray の細線。不要な目盛線は消す。
- 系列色は `design_tokens.json` に固定する。
- 直接ラベルを使い、凡例は必要な場合だけ残す。
- ピボットグラフのフィールドボタンは `ShowAllFieldButtons = False`。
- 3D グラフ、二重軸の多用、意味のないアニメーションを使わない。

### 9.2 個別ルール

- `PG-C01` は売上 1 系列。差額は KPI と DATA NOTE で補う。面グラフを使う場合は透過率 20〜25%。
- `PG-C02` は 2025 を Muted Blue、2026 を Coral。終点に直接ラベルを置く。横軸は月。
- `PG-C03` は降順。棒は Amber。商品名は横軸ではなく縦軸に置き、-45 度を避ける。
- `PG-C04` は 2 分類の 100% 積み上げ横棒。ラベルは分類名と %。円グラフにしない。

### 9.3 実装上の補助範囲

- `PG-C01` は `PT-03` の月別売上だけを `GETPIVOTDATA` で参照する補助範囲から描画する。これにより差額系列を含めず、折れ線 1 系列とする。
- `PG-C04` は `PT-01` の業種別売上を参照する隠し補助範囲から描画する。2 業種を 2 系列として配置し、1 本の 100% 積み上げ横棒にする。
- 補助範囲は `売上分析` の印刷範囲外に置く。通常ピボット、共有キャッシュ、スライサー接続は変更しない。
- Excel COM の PivotChart は PT の行・列配置により必要な系列方向を安定して設定できないため、上記 2 グラフは通常グラフとする。補助数式は各 PT から取得する値に連動する。スライサー操作による実機確認は未検証である。

### 10.1 3 状態

| 状態 | 判定 | 表示 | 塗り |
|---|---|---|---|
| 売上あり | `GETPIVOTDATA` 成功、0 以外 | `170万円` など | 3 色スケール |
| 売上 0 円 | `GETPIVOTDATA` 成功、0 | `0万円` | 3 色スケール最小色 |
| データなし | `GETPIVOTDATA` エラー、`COUNTIFS = 0` | `－` | Sand |
| 選択範囲外 | `GETPIVOTDATA` エラー、`COUNTIFS > 0` | 空欄 | 塗りなし |

- `IFERROR` を使わない。`ISERROR` と `COUNTIFS` を使う。
- 条件付き書式の適用範囲は `B51:Y58`。
- 優先度 1 は空欄、優先度 2 は文字列、優先度 3 は 3 色スケール。
- 優先度 1 と 2 は `StopIfTrue` を有効にする。
- 凡例は上部に置き、色だけでなく文字でも状態を示す。
- スパークラインは列種別、Coral、線幅 0.75。参照範囲は各行の `B51:Y51` から `B58:Y58`。

### 10.2 年別タイムライン追従

- 初期タイムラインは2026年である。PT-05 は PT-01〜PT-06 の一つとしてタイムラインに接続するため、初期状態では2025年のヒートマップセルは選択範囲外の空欄となる。データ欠損ではない。
- タイムラインを2025年だけにすると2025年の96セル、2026年だけにすると2026年の96セルを表示する。両年を選択すると両方の年が表示される。
- `verify_v06_windows.py` は一時コピーで3つの期間を切り替え、この挙動を自動検証する。

## 13. 注記

DATA NOTE には次を表示する。

1. 差額 = 売上 − 計上原価。
2. 前年比 = 2026 年 ÷ 2025 年 − 1。
3. タイムラインは前年比・前年比較に非連動。
4. 商品マスタは方式 A のため PT 未接続。

下部注記には次を表示する。

- 差額は売上履歴の計上原価のみを控除し、会計上の粗利・営業利益とは区別する。
- 売上データは架空データである。
- 商品追加時は商品マスタと売上データの両方へ登録する。
- 2025 年のヒートマップ列は、タイムラインを全期間へ広げるまで空欄である。

## 14. 印刷・アクセシビリティ・性能

### 14.1 印刷

- 横向き、A4、1 ページ幅に収める。

### 14.2 アクセシビリティ

- 本文のコントラスト比 4.5:1 以上を目安とする。
- 3 状態は色だけでなく文字と記号で区別する。
- 100% と 125% の表示倍率で確認する。
- 日本語の折り返し、文字切れ、重なりを確認する。

### 14.3 性能

- 開く時間、再計算時間、スライサー操作時間を記録する。
- v0.5 より著しく悪化させない。

## 3. グラフの補助範囲

Excel の PivotChart は PT の行・列配置により、月別売上の1系列化と業種構成の2系列化を安定して設定できなかった。そのため `PG-C01` と `PG-C04` は印刷範囲外の隠し補助セルを使う。補助セルは PT-03 / PT-01 の `GETPIVOTDATA` を参照し、追加の PT やキャッシュは作成していない。計算上の年別追従は自動検証済みであり、マウス操作による手動 UI 確認は未実施である。

コメント図形は `AutoShapeType=Rectangle` と `TextFrame.AutoSize=True` で整形し、74件すべて本文が保持されることを検証した。4グラフは最終列幅適用後に再配置し、各右端をQ列内に収めた。

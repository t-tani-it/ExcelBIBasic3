## 3. グラフの補助範囲

Excel の PivotChart は PT の行・列配置により、月別売上の 1 系列化と業種構成の 2 系列化を安定して設定できなかった。そのため、`PG-C01` と `PG-C04` は印刷範囲外の隠し補助セルを使用する。補助セルはそれぞれ PT-03 / PT-01 の `GETPIVOTDATA` を参照し、追加の PT やキャッシュは作成していない。スライサー操作で値が追従するかの手動確認は未実施である。

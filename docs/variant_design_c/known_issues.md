## 3. ビルド時の注意

- 出発点は `prototype_v04.xlsx` である。`prototype_v05_design_b.xlsx` は視覚参照と回帰基準であり、入力に使用しない。
- v0.4 / v0.5 ブックおよび v0.5 専用文書は変更しない。

## 3. 適用範囲
| 区分 | 範囲 |
|---|---|
| 作業環境 | Windows と Excel デスクトップアプリ |
| 技術的下限 | Excel 2016 Professional Plus（Power Pivot アドイン有効化） |
| 推奨下限 | Excel 2024 Professional または Microsoft 365 Apps |
| 実機保証 | なし（実機検証は Microsoft 365 の参照環境のみ） |
| 配布対象 | Windows のデスクトップ版。Mac、Excel Online、Home 系は対象外 |
| 対象外 | Excel 2013 以前（Power Query 非搭載） |

## 4. エディション制約の要点
- データモデル、DAX メジャー、CUBE 関数、GETPIVOTDATA（モデル ソース）は Professional 系以上のエディションを要する。
- Home 系エディションではデータモデルを利用できないため、本ブックは動作しない。
- セル内チェックボックスは Microsoft 365 に限定されるため、フォームコントロールを採用する。
- Power Pivot 専用エディタとモデル上の KPI と階層は使用しない。データモデルはメジャーとリレーションのみで構成する。

## 6. 互換性の判定方針
1. 成果物は技術的下限（Excel 2016 Professional Plus）で利用可能な機能のみで構成する。
2. 専用エディタ依存の機能（KPI、階層、計算列の高度な操作）は使用しない。
3. 実機未検証の版は「動作保証なし」と明示する。
4. 不成立時の代替は `docs/design_spec.md` の第 19 節による。

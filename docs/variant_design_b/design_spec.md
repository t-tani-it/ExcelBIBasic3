# デザインバリアント B 設計書（ExcelBIBasic3）

- 版: RevA
- 作成日: 2026-10-22
- 対象: `prototype_v05_design_b.xlsx`
- 出発点: `prototype_v04.xlsx`
- 目的: v0.4 方式 A の機能を維持し、`売上分析` シートだけを異なる UI で 0 から再作成する
- 優先順位: `AGENTS.md`、`docs/decision_log.md` の D-22、D-24、D-25、D-26、D-27、`docs/variant_requirements.md`、本設計書

## 1. 適用範囲

本設計書は v0.5 デザインバリアント B の UI、配置、配色、グラフ、ヒートマップ、検証方針を定める。v0.4 の仕様書とブックは変更しない。

- `prototype_v04.xlsx` を複製して作業を開始する。
- 既存の見積・原価・利益シート、`売上データ`、`商品マスタ`、`制御` の PT と共有キャッシュを維持する。
- `売上分析` シートを削除し、同名の新規シートを 0 から作成する。
- 新しい `売上分析` は `商品マスタ` の直前、シート索引 10 に配置する。
- 旧スライサーキャッシュを削除し、新しいスライサーキャッシュを作成する。
- 旧 `売上分析` のセル、書式、結合、入力規則、条件付き書式、図形、グラフ、スパークライン、印刷設定を継承しない。

## 2. デザイン方針

テーマは「Warm Slate」である。濃紺のスレート、コーラル、アンバー、クリームを組み合わせ、数字とフィルタの導線を明確にする。v0.4 の深緑・ティール系とは異なる印象とし、情報の優先順位を色と配置で示す。

- 左側にフィルタ帯を固定し、操作の起点を左にそろえる。
- KPI は 2 × 2 のカードとし、売上と差額を上段、差額率と前年比を下段に置く。
- グラフは 2 × 2 のグリッドとし、推移、前年比較、商品別、業種構成を並べる。
- ヒートマップは下部に全幅で置き、3 状態を色と文字で区別する。
- 注記は KPI 右の `DATA NOTE` とヒートマップ下部に分け、誤読を防ぐ。
- 色だけで状態を伝えない。状態の文字、記号、注記を併用する。

### 2.1 v0.4 との比較

| 項目 | v0.4 | v0.5 デザインバリアント B | 変更理由 |
|---|---|---|---|
| 配色 | 深緑、ティール、黄緑、淡緑 | スレート、コーラル、アンバー、クリーム | 暖色系のコントラストで KPI と注記を読み分けやすくする |
| KPI カード | 横 4 枚 | 2 × 2 の 4 枚 | 売上・差額と率・前年比の優先順位を分ける |
| グラフ構成 | 折れ線、集合縦棒、横棒、ドーナツ | エリア + 折れ線、折れ線 + マーカー、縦棒、円 | 推移と差額、前年比較、順位、構成比を種類で区別する |
| スライサー | 上部に横並び | 左側のフィルタ帯に縦並び | 操作の起点を固定し、グラフ領域を広く使う |
| ヒートマップ | 緑系 3 色、条件付き書式 2 件 | 暖色系 3 色、条件付き書式 3 件 | 0 円、データなし、選択範囲外を区別する |
| スパークライン | 商品行ごとに 8 本 | 列スパークライン 8 本 | 月次の山谷を棒の高さで比較しやすくする |
| 注記 | 下部に集約 | DATA NOTE と下部注記に分割 | 読み取りのポイントを KPI の近くに置く |

デザイン差は、配色、KPI カード、グラフ構成の 3 項目で v0.4 から変更している。要件の最低条件である 2 項目以上を満たす。

## 3. UI の採用元とライセンス

| 項目 | 内容 |
|---|---|
| 外部 UI の採用 | なし |
| 採用元 | 自作。外部のテンプレート、画像、アイコン、レイアウト素材を使用しない |
| 採用理由 | v0.4 の機能を維持したまま、暖色系の配色、2 × 2 の KPI、左側フィルタ帯で情報の優先順位を明確にするため |

外部 UI を採用していないため、出典 URL とライセンス表記は不要である。採用時は、採用元、理由、ライセンスを本表へ追記する。

### 9.1 3 状態の判定

各セルの基本式は次の構造である。例は `B51` である。

```text
=IF($A51="","",
  IF(ISERROR(GETPIVOTDATA("売上（万円）",制御!$H$2,"商品",$A51,"年月",B$50)),
    IF(COUNTIFS(SalesHistory[商品],$A51,SalesHistory[年月],B$50)=0,"－",""),
    ROUND(GETPIVOTDATA("売上（万円）",制御!$H$2,"商品",$A51,"年月",B$50),0)
  )
)
```

| 状態 | 判定 | 表示 | 塗り |
|---|---|---|---|
| 売上あり | `GETPIVOTDATA` 成功、値が 0 以外 | `170万円` など | 3 色スケール |
| 売上 0 円 | `GETPIVOTDATA` 成功、値が 0 | `0万円` | 3 色スケールの最小色 |
| データなし | `GETPIVOTDATA` エラー、`COUNTIFS = 0` | `－` | サンド |
| 選択範囲外 | `GETPIVOTDATA` エラー、`COUNTIFS > 0` | 空欄 | 塗りなし |

- `IFERROR` は使用しない。`GETPIVOTDATA` のエラーを `ISERROR` で判定し、`COUNTIFS` でデータなしと選択範囲外を分ける。
- データなしは `－` とサンド塗り、選択範囲外は空欄と塗りなしで区別する。
- 売上 0 円は数値 0 と `0"万円"` 書式で `0万円` と表示する。数値 0 は空白でも文字列でもないため、色スケールの対象になる。
- 商品名が空欄の行は、数式の先頭で空欄を返す。

### 9.2 条件付き書式

| 優先度 | 種類 | 条件 | 書式 | 停止 |
|---|---|---|---|---|
| 1 | 数式 | `=B51=""` | 塗りなし | する |
| 2 | 数式 | `=ISTEXT(B51)` | サンド塗り、コーラル太字 | する |
| 3 | 3 色スケール | 最小、50 パーセンタイル、最大 | ライトピーチ、アンバー、コーラル | - |

- 条件付き書式の適用範囲は `B51:Y58` である。
- 優先度 1 と 2 は `StopIfTrue` を有効にする。
- 3 色スケールは数値セルだけに適用する。文字列 `－` と空欄は優先度 1 と 2 で停止する。
- スパークラインは列種別、系列色コーラル、線幅 0.75 とする。参照範囲は各行の `B51:Y51` から `B58:Y58` である。

### 9.3 凡例と注記

`A60` の凡例は次のとおりである。

```text
0万円 = 売上0 / － = データなし / 空欄 = 選択範囲外（フィルタ・期間）
```

`A62` の注記は次のとおりである。

```text
差額は売上履歴の計上原価のみを控除。会計上の粗利・営業利益とは区別します。商品マスタは方式AのためPT未接続です。
```

- マクロなしの `.xlsx` とする。VBA、ActiveX、マクロブックを含めない。

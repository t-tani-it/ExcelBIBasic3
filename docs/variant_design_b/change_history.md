# デザインバリアント B 変更履歴（ExcelBIBasic3）

- 版: RevA
- 作成日: 2026-10-22
- 対象: `prototype_v05_design_b.xlsx`
- 比較元: `prototype_v04.xlsx`

## 1. 変更の概要

v0.5 は v0.4 の複製から `売上分析` シートだけを削除し、同名のシートを 0 から再作成したデザインバリアントである。見積・原価・利益、売上データ、商品マスタ、制御シートの PT と共有キャッシュは維持する。

- テーマを「Warm Slate」へ変更する。
- KPI を横 4 枚から 2 × 2 のカードへ変更する。
- グラフを折れ線、集合縦棒、横棒、ドーナツから、エリア + 折れ線、折れ線 + マーカー、縦棒、円へ変更する。
- スライサーとタイムラインを上部の横並びから左側のフィルタ帯へ変更する。
- ヒートマップを緑系から暖色系へ変更し、3 状態を区別する。
- スパークラインを列種別へ変更する。
- 注記を `DATA NOTE` と下部注記へ分割する。

## 5. 実装上の変更

- `売上分析` を削除する前に、旧スライサーキャッシュを削除する。
- 旧スライサーキャッシュは `SL_業種`、`SL_商品`、`TL_日付` である。
- 新しいスライサーキャッシュは `SL_業種_B`、`SL_商品_B`、`TL_日付_B` である。
- PT-01 から PT-08 と共有キャッシュ 1 個は再利用する。
- 新しい `売上分析` は `商品マスタ` の直前へ作成する。
- KPI は `E6`、`I6`、`E11`、`I11` に配置する。
- グラフは `PG-B01` から `PG-B04` の 4 個を作成する。
- ヒートマップは `B51:Y58` の 192 セルと `Z51:Z58` の 8 本のスパークラインを作成する。
- 印刷範囲は `A1:Z62`、横向き、1 ページに設定する。
- 保存後に OOXML を後処理し、絶対パスと作成者情報を除去する。

## 6. 実装中に修正した点

| 事象 | 対応 |
|---|---|
| `XL_TOP` 未定義でビルドが停止 | 定数 `XL_TOP = -4160` を追加 |
| タイムラインの `TimelineStyleLight2` 設定失敗 | `TimeSlicerStyleLight1` へフォールバック |
| ピボットグラフのフィールドボタン表示 | `ShowAllFieldButtons = False` を追加 |
| 円グラフの 3 色目が存在しない場合の例外 | ポイント数に合わせて色設定を打ち切り |
| ヒートマップの `IFERROR` 検査が複数セルで効かない | セルごとに `HasFormula` と `Formula` を確認 |
| サイドバー幅とタイムライン幅の不一致 | 列幅を A 24、B:Y 11、Z 18 に調整し、タイムラインを 225 幅へ変更 |
| 上部の余白とバッジ位置 | 上部線を `A4:Z4`、バッジを `Y2:Z2` へ変更 |
| 商品別グラフのラベル切れ | 横軸ラベルを 7 pt へ変更 |
| データなしの塗りが 0 円と似ている | テキストルールの塗りをサンドへ変更 |

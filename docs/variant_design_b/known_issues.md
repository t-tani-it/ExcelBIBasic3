# デザインバリアント B 既知の問題（ExcelBIBasic3）

- 版: RevA
- 作成日: 2026-10-22
- 対象: `prototype_v05_design_b.xlsx`
- 目的: 制約、未実装、未検証、設計上の判断を記録する

## 1. 既知の問題と制約

| ID | 内容 | 影響 | 対応・回避 |
|---|---|---|---|
| KI-B-01 | タイムラインの `TimelineStyleLight2` 設定が COM エラーで失敗する | ビルド時にスタイル設定の例外が記録される | 既定の `TimeSlicerStyleLight1` を使用する。表示、接続、初期範囲は検証済み |
| KI-B-02 | 手動 UI 操作が未検証である | スライサーのクリック、複数選択、タイムラインのドラッグ、再起動後の状態は未保証 | 購入者または次の担当者が実操作で確認する |
| KI-B-03 | 実印刷が未検証である | 用紙サイズ、横向き 1 ページの可読性、余白、改ページは未保証 | 実プリンタで確認する。必要なら印刷範囲または倍率を調整する |
| KI-B-04 | 性能が未測定である | 192 セルの `GETPIVOTDATA`、8 本のスパークライン、4 グラフの操作感は未保証 | 低スペック端末で操作時間を計測する |
| KI-B-05 | 現行データに 0 円とデータなしの実セルがない | 既定表示では 3 状態のうち 2 状態を目視できない | 一時コピーと検証式で確認済み。凡例で意味を明示する |
| KI-B-06 | 2025 年のヒートマップ列は初期状態で空欄である | 2025 年の値が見えない | タイムラインを 2025-01-01 から 2026-12-31 へ広げる |
| KI-B-07 | 前年比は 2026 年と 2025 年の固定比較である | 年をまたぐ可変比較はできない | 要件どおり固定とする。変更時は別要件とする |
| KI-B-08 | 商品マスタは PT とスライサーに未接続である | 商品マスタの追加だけではスライサーへ反映されない | 商品マスタと `SalesHistory` の両方へ登録し、PT を更新する |
| KI-B-09 | ヒートマップは `GETPIVOTDATA` のフィールド名に依存する | PT のフィールド名変更で判定が変わる | ビルドと検証でフィールド名を確認する。変更時は数式も更新する |
| KI-B-10 | `COUNTIFS` は `SalesHistory[商品]` と `SalesHistory[年月]` に依存する | テーブル名・列名の変更で数式が壊れる | テーブル名と列名を維持する。変更時は全 192 セルを再生成する |
| KI-B-11 | 対応版は Microsoft 365 のみ実機確認済みである | Excel 2016、2019、2021、2024 の動作は未保証 | 対象版で実機確認する。未確認版を保証しない |
| KI-B-12 | ビルドは v0.4 のブックがロックされていないことを前提とする | ソースが開かれているとビルドに失敗する可能性がある | v0.4 を閉じるか、複製した入力を使う |
| KI-B-13 | 旧スライサーキャッシュ名との互換性がない | `SL_業種`、`SL_商品`、`TL_日付` を参照する外部マクロは動作しない | 本ブックはマクロなしの方針であり、外部マクロ連携は対象外とする |
| KI-B-14 | 返品、複数税率、年度締め、ゲージ、目標テーブル、チェックボックスは未実装である | これらの業務処理はできない | v0.5 の対象外とする。必要時に別要件とする |
| KI-B-15 | 色覚多様性への配色検証は未実施である | 色の見え方によってはコントラストが低下する可能性がある | 状態は文字と記号でも区別する。必要時にコントラスト比を測定する |

## 2. 設計上の判断

次は不具合ではなく、v0.5 の設計判断である。

- KPI は 4 表示を維持し、2 × 2 に配置する。売上と差額を上段、率と前年比を下段に置く。
- スライサーは左側のフィルタ帯に置く。上部の横並びより、グラフ領域を広く使える。
- `PG-B01` はエリアと折れ線の複合とする。売上規模と差額の動きを同時に読むためである。
- `PG-B03` は横棒ではなく縦棒とする。商品名を -45 度で表示し、順位を左から右へ読む。
- `PG-B04` はドーナツではなく円とする。2 業種の構成比を単純化するためである。
- スパークラインは線ではなく列とする。月次の山谷を棒の高さで比較しやすくするためである。
- ヒートマップのデータなしは `－` とサンド、選択範囲外は空欄と塗りなしとする。0 円は `0万円` と色スケール最小色とする。
- ヒートマップに `IFERROR` を使用しない。`GETPIVOTDATA` のエラーを `ISERROR` で受け、`COUNTIFS` でデータなしと選択範囲外を分ける。

## 3. 解決済みの問題

| 内容 | 対応 |
|---|---|
| タイムラインのスタイル設定エラー | `TimeSlicerStyleLight1` へフォールバックし、表示と接続を検証 |
| 検証スクリプトのスライサースタイル比較 | COM オブジェクトを `str()` で比較 |
| 8 番目の商品名の期待値誤記 | `季節の果物` へ修正 |
| データなしの塗りがライトピーチのまま | サンドへ変更し、再ビルド |
| ピボットグラフのフィールドボタン表示 | `ShowAllFieldButtons = False` で非表示 |
| 上部の余白とバッジ位置 | 上部線を `A4:Z4` へ拡張し、バッジを `Y2:Z2` へ移動 |

## 5. 次のアクション

1. スライサー、タイムライン、再起動後の状態を Excel 実機で確認する。
2. 横向き 1 ページの実印刷を確認する。必要なら倍率と余白を調整する。
3. 低スペック端末で操作時間を計測する。
4. 商品追加の操作手順を確認し、`商品マスタ` と `SalesHistory` の両方へ登録する。
5. 必要に応じて Excel 2016、2019、2021、2024 で実機確認する。
6. 色覚多様性の観点で、コーラル、アンバー、サンドのコントラスト比を確認する。

## 6. 禁止事項

- ヒートマップへ `IFERROR` を再導入しない。
- `ProductMaster` を PT またはスライサーへ接続しない。
- v0.4 のブックと文書を上書きしない。
- メモ 74 件と `INDIRECT` 24 件を削除しない。
- シート保護、セル保護、ウィンドウ枠固定を追加しない。
- VBA、外部リンク、Power Query、データモデル、DAX、リレーション、CUBE 関数を追加しない。

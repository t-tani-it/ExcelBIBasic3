## 4. ヒートマップの 3 状態

3 状態は一時コピーで個別に検査した。検証対象のブックは保存しない。

### 4.1 0 円

- 一時コピーの `SalesHistory` で、`テーブル` の 2026-01 の売上 3 行を 0 円へ変更する。
- PT を更新し、`売上分析!N51` を確認する。
- 結果は数値 0、表示は `0万円` である。
- 0 円は数値セルであり、空白でも文字列でもない。色スケールの最小色が適用される。

### 4.2 データなし

- 一時コピーの `AA1` に `未登録商品`、`AA2` に `2026-01` を置く。
- ヒートマップと同じ `ISERROR` と `COUNTIFS` の検証式を `AA3` に置く。
- 結果は `－` である。
- 現行の 8 商品 × 24 か月にはデータなしの組合せがないため、実セルではなく同じ判定式で確認する。

### 4.3 選択範囲外

- `テーブル` の 2025-01 は、タイムライン初期値が 2026 年のため PT の対象外である。
- 実際の `B51` は空欄で、塗りなしである。
- 一時コピーの検証式でも、`COUNTIFS > 0` かつ `GETPIVOTDATA` エラーの場合は空欄を返すことを確認する。

### 4.4 既存データ

- `テーブル` の 2026-01 は 170 万円である。
- 同じ検証式で 170 を返すことを確認する。

## 7. 初回実行からの修正

初回の検証では 233 件中 228 件が合格し、5 件が不合格であった。原因は成果物の不具合ではなく、検証式とビルド前の一時状態にあった。

| 不合格 | 原因 | 対応 |
|---|---|---|
| 業種スライサーのスタイル | COM の `Style` を文字列比較したため | `str()` で比較 |
| 商品スライサーのスタイル | 同上 | `str()` で比較 |
| タイムラインのスタイル | 同上 | `str()` で比較 |
| 8 番目の商品名 | 期待値を `手編みの果物` と誤記 | 実データの `季節の果物` へ修正 |
| データなしの塗り | サンドへ変更する前のブックを検証 | 再ビルド後に再検証 |

再ビルドと検証式の修正後、233 / 233 合格となった。

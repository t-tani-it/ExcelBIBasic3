## 4. Power Query クエリ
| ID | 名前 | ソース | 出力 | 内容 |
|---|---|---|---|---|
| PQ-01 | qrySales | テーブル `SalesHistory`（売上データ!A4:I580） | データモデルのみ | 型変換、年月列の追加、データ区分の維持 |
| PQ-02 | qryProduct | テーブル `ProductMaster`（商品マスタ） | データモデルのみ | 型変換、表示順の整数化、有効フラグの真偽値化 |
| PQ-03 | qryCalendar | 生成（`#date(2025,1,1)` から `#date(2026,12,31)`） | データモデルのみ | 日付、年、月、年月、年月表示、年月順の追加 |

- 外部ソースは使用しない。すべてブック内のテーブルまたは生成である。
- PQ-01 の 年月 は `Text.From([年]) & "-" & Text.PadStart(Text.From([月]),2,"0")` とする。
- PQ-03 の 年月順 は `[年]*12+[月]` とする。
- 更新は「すべて更新」1 操作で完結する。クエリのロード先は「データモデルのみ」とする。

## 5. データモデル
### 5.1 テーブル
| テーブル | 列 | 備考 |
|---|---|---|
| SalesHistory | 日付、業種、商品、数量、税抜単価、税抜売上、計上原価、計上原価控除後差額、データ区分、年月 | ファクト |
| 商品マスタ | 商品 ID、商品名、業種、表示順、有効 | ディメンション |
| 日付マスタ | 日付、年、月、年月、年月表示、年月順 | ディメンション |

### 5.2 リレーション
| 从 | 至 | カーディナリティ |
|---|---|---|
| SalesHistory[商品] | 商品マスタ[商品名] | 多対一 |
| SalesHistory[日付] | 日付マスタ[日付] | 多対一 |

### 5.3 DAX メジャー
| 名前 | 定義 | 備考 |
|---|---|---|
| 売上 | `SUM(SalesHistory[税抜売上])` | 円 |
| 計上原価 | `SUM(SalesHistory[計上原価])` | 円 |
| 差額 | `[売上]-[計上原価]` | 円 |
| 差額率 | `IF([売上]=0,BLANK(),DIVIDE([差額],[売上]))` | 比率 |
| 件数 | `COUNTROWS(SalesHistory)` | 件 |
| 前年売上 | 前年同期の売上 | 第 5.4 節 |
| 前年比 | `IF([前年売上]=0,BLANK(),DIVIDE([売上],[前年売上])-1)` | 比率 |

### 5.4 前年売上の実装優先順
1. 日付マスタを「日付テーブルとしてマーク」し、`SAMEPERIODLASTYEAR(日付マスタ[日付])` を使用する。
2. マーク設定が不可の場合、`CALCULATE([売上], FILTER(ALL(日付マスタ), 日付マスタ[年] = MAX(日付マスタ[年]) - 1), KEEPFILTERS(VALUES(日付マスタ[月])))` を使用する。
3. いずれも不可の場合は前年比を非表示とし、PG-02 の前年系列で代替する。

- 定義は「選択中の月集合と同じ月の前年分」とする。年をまたぐ選択では月集合の共通部分を対象とする。

## 9. KPI
| セル | 表示 | 式の第一候補 |
|---|---|---|
| A9 | 税抜売上（円） | `=ROUND(CUBEVALUE("ThisWorkbookDataModel","[Measures].[売上]",Slicer_業種,Slicer_商品),0)` |
| D9 | 差額（円） | `=ROUND(CUBEVALUE("ThisWorkbookDataModel","[Measures].[差額]",Slicer_業種,Slicer_商品),0)` |
| G9 | 差額率 | `=IF(A9=0,"算出不可",D9/A9)` |
| J9 | 前年比 | `=IF(前年売上=0,"算出不可",売上/前年売上-1)` |

- `Slicer_業種` と `Slicer_商品` はスライサーの名称とする。名称は作成時に固定する。
- タイムラインは CUBE 式の引数に指定しない。タイムラインの選択はスライサーのフィルタ状態として反映されるかを実機で確認する。
- タイムラインが CUBE 式へ反映されない場合は、KPI を PT-05 の `GETPIVOTDATA` へ切替する。切替時は 4 表示すべてを同時に切り替える。

## 10. ヒートマップ
| 項目 | 仕様 |
|---|---|
| 配置 | 売上分析!B46:Y65（最大 20 商品 × 24 か月） |
| 値 | `=ROUND(集計値/10000,0)` |
| 書式 | `0"万円"` |
| 色 | 3 色スケール。淡緑 `#DDEFE3`、中間 `#7FC7B2`、濃ティール `#1F7A66` |
| 0 円 | 値 0、最淡色 |
| データなし | `ISNA` のみ `－` へ変換 |
| 選択範囲外 | 空欄、塗りなし |
| 行見出し | 商品マスタの表示順。商品追加時は行とスパークラインを追加 |

- 第一候補はデータモデルを参照する CUBE 式とする。時間経過の制御と列ズレ防止のため、列は年月固定とする。
- 再計算が目標性能を満たさない場合は、PT-06 と同型の行列ピボットと条件付き書式へ切替する。

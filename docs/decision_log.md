## D-22 データモデル方式の実行不能（実測）

| 項目 | 内容 |
|---|---|
| 決定 | 本ビルド環境では Power Query のデータモデル接続を作成しない。売上分析は v0.2 の SUMIFS 版を維持し、Power Query・データモデル・ピボット化は別環境での再実装とする |
| 根拠 | `Connections.Add2(..., CreateModelConnection=True)` と `Model.Refresh` が、`Excel.CurrentWorkbook()` を参照するクエリの評価時に応答しない。Excel 内部マクロ、`Application.OnTime`、可視インスタンスのいずれでも同一現象 |
| 実測 | クエリ定義（`Queries.Add`）と接続定義（`CreateModelConnection=False`）は成功。`#table` リテラルのモデル接続は成功（2 行）。ワークシートテーブル参照のクエリはモデル接続作成で 10 分以上停止。ダイアログウィンドウは存在しない |
| 影響 | モデル テーブル名は自動命名（クエリ、クエリ 1）であり COM から改名できない。通常のピボットキャッシュは作成可能 |
| 状態 | 確定（2026-10-21 実測） |
| 再開条件 | 対話セッションで Excel を起動し、手動でクエリをデータモデルへ読み込めることを確認できた環境 |

# v0.6 受入マトリクス（ExcelBIBasic_DeepSeek_V4.1）

- 版: RevC
- 作成日: 2026-10-22
- 対象: `prototype_v06_design_c.xlsx`
- 目的: 固定要件、回帰値、デザイン品質、手動確認を 1 枚で判定する

## 1. 判定の全体像

v0.6 の合格は、次の 4 つをすべて満たすことである。

1. 自動検証 233 件以上合格（現行 v0.6 は 259 / 259）
2. デザイン点数 20 / 24 以上、重大項目に 0 がない
3. 手動確認の重大項目が合格、または未検証として明記されている
4. 公開禁止情報が 0 件

233 件以上は機能と回帰の合格であり、デザイン品質の合格ではない。両方を確認する。

## 9. 停止条件

次のいずれかに該当したら、作業を止めて記録する。

- 233 件の既存チェックが 1 件でも落ちる。
- 既存計算、メモ 74、`INDIRECT` 24 が変わる。
- ヒートマップの 3 状態が崩れる。
- 外部リンク、保護、固定枠、VBA、PQ、モデルが入る。
- デザイン点数が 20 点未満、または重大項目に 0 がある。
- ライセンス不明の素材が必要になる。
- 2 回再ビルドしても改善しない。

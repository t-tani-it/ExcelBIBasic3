# 計算仕様（ExcelBIBasic3）

- 版: RevA
- 作成日: 2026-10-21
- 対象: 関数による即時再計算（見積・原価・利益）と、データモデル由来の表示値

## 1. 適用範囲
- 維持対象: 見積入力、計算、採算シミュレーション、原価(木工所)、原価(農家)、見積書。
- 新規対象: 売上分析（KPI、ヒートマップ、スパークライン、ゲージ、チェックボックス）。
- 原則: 保存値は円とする。万円は表示変換に限る。

## 2. 丸め原則
| 対象 | 丸め | 備考 |
|---|---|---|
| 明細の税抜金額 | `ROUND(D*F,0)` | 円単位 |
| 試算売上 | `ROUND(基準売上*(1-試算値引率),0)` | 明細単位 |
| 試算原価 | `ROUND(原価*(1+原価増減率),0)` | 明細単位 |
| 確定売上 | `ROUND(基準売上*(1-確定値引率),0)` | 明細単位 |
| 税額 | `ROUNDDOWN(対象額*税率,0)` | 税率別 |
| 試算共通費 | `ROUND(案件共通費*(1+原価増減率),0)` | 案件単位 |
| 目標必要売価 | `ROUNDUP(試算原価/(1-目標利益率),0)` | 案件単位 |
| 万円表示 | `ROUND(円/10000,0)` | 最大 ±0.5 万円の表示誤差 |

## 3. 既存計算式（実測値、維持）

### 3.1 見積入力
| セル | 式 | 説明 |
|---|---|---|
| H16:H25 | `=IF(I16="OK",ROUND(D16*F16,0),"")` | 明細の税抜金額。入力確認が OK のときのみ算出 |
| I16:I25 | 予約語、特殊文字、数量、単価、税率の妥当性検査 | 明細単位の入力確認 |
| I28 | `=IF(COUNTIFS(I16:I25,"OK")=0,"見積明細なし",IF(SUMPRODUCT((I16:I25<>"")*(I16:I25<>"OK"))>0,"見積明細を確認",IF(OR(NOT(ISNUMBER(B8)),B8<0,B8>1),"確定値引率を確認","OK")))` | 入力状態。OK のとき下流が有効 |

## 4. 計算順序（試算側）
1. 入力確認（見積入力 I16:I25、I28）と原価入力状態（原価 M5）の確定。
2. 総合状態（計算 B10）の確定。OK 以外では試算値と確定値が空欄となる。
3. 対象原価の判定と原価増減率の適用。`ROUND(D*(1+増減率),0)` の順序を固定する。
4. 試算共通費の算出。共通費へ増減率を適用し、明細原価へは適用しない。
5. 試算売上と試算原価の合算、予定案件利益と利益率の算出。
6. 目標必要売価の算出。`ROUNDUP(試算原価/(1-目標利益率),0)` とする。
7. 確定側の算出。確定値引率は `見積入力!B8` のみを参照し、試算値引率を参照しない。

## 5. 新規計算（売上分析）
### 5.1 KPI
| 表示 | 計算 | 第一候補 | 代替 |
|---|---|---|---|
| 税抜売上 | DAX メジャー「売上」の合計 | `CUBEVALUE` | `GETPIVOTDATA` |
| 計上原価控除後差額 | DAX メジャー「差額」 | `CUBEVALUE` | `GETPIVOTDATA` |
| 差額率 | `IF(売上=0,"算出不可",差額/売上)` | `CUBEVALUE` の組合せ | `GETPIVOTDATA` |
| 前年比 | `IF(前年売上=0,"算出不可",売上/前年売上-1)` | `CUBEVALUE` の組合せ | `GETPIVOTDATA` |

- 前年売上の DAX メジャーは `CALCULATE` と `FILTER` で年月を 12 か月前へずらす方式とする。日付テーブルのマーク設定に依存しない。
- CUBE 関数とスライサーの連動が実機で成立しない場合は、KPI 用 PT の `GETPIVOTDATA` へ一括切替する。

### 5.2 ヒートマップ
| 項目 | 仕様 |
|---|---|
| 格子 | 商品（行、最大 20）× 年月（列、24 固定） |
| 値 | `ROUND(集計値/10000,0)`。書式 `0"万円"` |
| 色 | 3 色スケール（淡緑、中間、濃ティール）。0 円は最淡色 |
| データなし | `ISNA` のみ `－` へ変換。他のエラーは表示 |
| 選択範囲外 | 空欄。塗りなし |

### 5.3 ゲージ
| 項目 | 計算 |
|---|---|
| 実績 | `SUMIFS(月次実績, 業種, 入力業種, 年月, >=開始, 年月, <=終了)` |
| 目標 | `SUMIFS(目標テーブル, 業種, 入力業種, 年月, >=開始, 年月, <=終了)` |
| 達成率 | `IF(目標=0,"目標未設定",実績/目標)` |
| 残額 | `MAX(0, 目標-実績)` |
| 表示 | データバー。達成率セルへ適用。基準色はティール |

- 月次実績はスライサー非連動の独立 PT から取得する。CUBE 関数のスライサー引数は使用しない。
- 評価期間の入力は画面の 3 セルとする。スライサーとタイムラインの影響を受けない旨を直近のセルへ明記する。

### 5.4 チェックボックス
| ID | 条件 | 既定 | 効果 |
|---|---|---|---|
| CB-1 | 共通費を試算へ含める | ON | OFF のとき試算原価から試算共通費を除外 |
| CB-2 | 条件該当の原価のみ算入 | ON | OFF のとき原価増減率の適用対象を全明細へ拡大 |
| CB-3 | 差額率で目標判定 | OFF | ON のとき D12 の判定を差額率と目標利益率の比較へ変更 |

- リンクセルは制御用セル（非表示シート）とする。値は TRUE と FALSE である。
- 影響範囲は試算側（計算 F、G、B30、B31、B41、D12）に限定する。確定側（H、B36、B37、B38、B39）は影響を受けない。

## 7. 採算シミュレーション D12 の状態
| 状態 | 条件 | 色 |
|---|---|---|
| 目標達成 | 利益率が目標利益率以上 | 淡緑 |
| 黒字・目標未達 | 利益が 0 以上かつ目標未達 | 淡黄 |
| 赤字 | 利益が負 | 淡赤 |
| 算出不可 | 試算売上が 0 | 淡赤 |
| 確認 | 計算 B10 が OK 以外 | 淡赤 |

- 条件付き書式は 3 規則（正常、未達、異常）とし、数式による判定を用いる。値の式は既存の D12 を維持する。

## 8. 表示状態の判定（万円表示）
| 実データ | 表示 | 判定式 |
|---|---|---|
| 売上あり | `84万円` | 数値 |
| 売上 0 円 | `0万円` | 数値 0 |
| データなし | `－` | `ISNA` のときのみ変換 |
| 選択範囲外 | 空欄 | 空文字または空白 |

- `IFERROR(...,0)` による一律の隠蔽は禁止する。
- 円未満は四捨五入する。表示の丸め誤差は最大 ±0.5 万円である。
